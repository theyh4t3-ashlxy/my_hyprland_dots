# kitty

gpu-accelerated terminal emulator where i type git commands i barely understand.

font rendering go brrr

- `kitty.conf`: padding, blur, tabs, keybinds, and font overrides.
- `colors.conf`: gets violently rewritten by matugen every time the wallpaper changes.

if kitty doesn't update its palette after a wallpaper switch, blame `pkill -USR1 kitty`.

# corners

concave corner scoops and continuous screen frame borders.

sharp screen edges are a hate crime

creates true curved display bezels using layer-shell subsurfaces.

- `ConcaveCorner.qml`: canvas element rendering mathematical inner arc scoops matching bar thickness and corner radius.
- `ScreenCorners.qml`: orchestrates all four display corners and continuous border lines across monitor edges with proper region masking so clicks pass through to windows.

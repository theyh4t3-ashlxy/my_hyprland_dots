# widgets

all desktop pills, menus, drawers, and status indicators.

this is where 90% of the vibe lives

- `AppLauncher.qml`: searchable application launcher with category tags and frecency ranking.
- `BarStudio.qml`: live interactive visual editor to drag, reorder, and position widgets across left, center, and right bar sections.
- `Battery.qml`: battery percentage and power profile indicator.
- `Bluetooth.qml`: bluez device discovery, connection, and battery level card.
- `Clipboard.qml`: searchable clipboard history drawer with one-click copy and delete.
- `Clock.qml`: clock and calendar popup.
- `IdleInhibitor.qml`: caffeine pill preventing the screen from sleeping during movies or compilation.
- `MotionSandbox.qml`: live interactive physics and animation playground.
- `NetworkStatus.qml`: wifi ssid selector and connection status pill.
- `Notifications.qml`: notification center drawer showing notification history with quick toggles.
- `NowPlaying.qml`: mpris media player controller with album art, scrub bar, and media controls.
- `PowerMenu.qml`: session management modal (lock, logout, sleep, reboot, shutdown).
- `QuickNotes.qml`: persistent scratchpad for brain dumps and temporary pastebin snippets.
- `QuickSettings.qml`: unified control center panel with sliders, quick toggles, and vibe settings.
- `SystemTray.qml`: status notifier item (sni) tray for background applets.
- `VolumeControl.qml`: pipewire audio mixer with sink selectors and per-app stream volumes.
- `WallpaperBrowser.qml`: visual grid browser to preview and apply wallpapers on the fly.
- `WindowTitle.qml`: active hyprland window title and app class indicator.
- `Workspaces.qml`: interactive hyprland workspace switcher with urgent state indicators.

# osd

for when you smash your volume keys six times in a row and need immediate visual validation that your system isn't frozen.

on-screen display popups for volume, mute, and display brightness changes. simple, fast, unobtrusive.

## files
- `OSD.qml`: transient floating pill that slides smoothly onto the screen when volume or brightness keys are pressed. displays dynamic progress sliders and material symbols icons before gracefully fading into the shadows once you stop mashing the keyboard.

# components

pure geometric sorcery. high school trigonometry weaponized against ugly square borders.

if you are writing hardcoded pixel coordinates or suffering through ugly rectangular window cuts, stop. this directory contains the math routines that draw inverse curves so your docked bars melt directly into the display edge like hot butter.

## files
- `ConcaveCurves.qml`: html5 canvas paths rendered in native qml. draws mathematically precise concave arcs that fill the negative space between a floating bar pill and the outer monitor boundary. look at it too closely and your gpu might develop sentience.

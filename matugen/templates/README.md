# templates

the blueprint graveyard for matugen.

curly braces and hex tokens everywhere

contains all the skeleton templates that matugen injects wallpaper colors into:
- `Theme.qml`: quickshell's divine color palette.
- `hyprland-colors.lua`: window border gradients.
- `kitty-colors.conf`: terminal colors.
- `fastfetch-colors.jsonc`: flex banner colors.
- `gtk3.css` & `gtk4.css`: gtk stylesheet injection.
- `nvim-colors.lua`: neovim syntax highlighting.
- `yazi-theme.toml`: terminal file manager drip.
- `zsh-colors.zsh`: shell prompt highlights.

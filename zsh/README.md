# zsh

over-engineered zsh environment compiled to bytecode (.zwc) for instant startup.

if your shell takes more than 10ms to load you failed

- `core.zsh`: shell options, history, line editor.
- `prompt.zsh`: dynamic prompt engine (two-line, single-line, minimal, unhinged).
- `settings.zsh`: interactive terminal customizer.
- `roast.zsh`: tracks your command typos and roasts your cognitive decline.
- `dnd.zsh`: do not disturb toggle from the cli.
- `wp.zsh`: wallpaper manager commands (`wp random`, `wp set`, `wp next`).
- `aliases.zsh`: sanity-saving shortcuts.
- `help.zsh`: pretty-printed terminal cheat sheet.
- `nuke.zsh`: emergency cleanup utilities.
- `matugen.zsh`: shell colors piped from matugen.
